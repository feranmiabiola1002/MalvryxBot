# ⚡ MALVRYX BOT

A powerful Telegram bot with web dashboard, admin snatching, and attack features.

## 🚀 Features

- 🔥 Attack commands (crash, flood)
- 👑 Admin snatching
- 🌐 Web dashboard
- 📱 Mobile responsive
- ⚡ Fast and lightweight

## 📦 Deployment

### Render

1. Fork this repo
2. Create Web Service on Render
3. Add environment variables:
   - `API_ID`
   - `API_HASH`
   - `BOT_TOKEN`
   - `LOG_CHANNEL`
   - `ADMIN_USER_IDS`
4. Deploy!

## 📱 Commands

- `.crash <target>` - Text bomb
- `.flood <target>` - Spam messages
- `.snatch <chat_id>` - Snatch admins
- `.delay <seconds>` - Set delay
- `.mode <public/private>` - Set mode
- `.status` - Show status
- `.destroy` - Self-destruct
